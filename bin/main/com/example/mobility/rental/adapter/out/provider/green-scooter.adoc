# Support for Green Scooter Integration

1. Add a Green Scooter client and its request/response types.
  1.1  new package greenscooter
  1.2  Define request and response types for the Green Scooter client.
  1.3  Implement the Green Scooter client using the defined request and response types.
2. Add an adapter implementing RentalProviderPort, translating the provider’s protocol into application types.
  1.1  GreenScooterRentalAdapter implements RentalProviderPort
  1.2  Implement the GreenScooterRentalAdapter using the Green Scooter client.
3. Register the adapter as a Spring bean and test its mapping, failures, and registration.
